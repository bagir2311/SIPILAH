# 📱 Sipilah - AI Assistant App

**Sipilah** adalah aplikasi mobile cerdas yang dibangun menggunakan **React Native (Expo)**. Aplikasi ini mengintegrasikan autentikasi pengguna yang aman dan asisten AI canggih untuk membantu aktivitas sehari-hari.

![Status](https://img.shields.io/badge/Status-Development-orange)
![Tech](https://img.shields.io/badge/Built%20With-Expo%20%7C%20Firebase%20%7C%20Gemini-blue)

## 🚀 Fitur Utama

* **🔐 Autentikasi Aman:** Login dan Register menggunakan Email/Password (Firebase Auth).
* **🤖 AI Chatbot:** Asisten pintar yang ditenagai oleh Google Gemini AI.
* **🔥 Cloud Database:** Penyimpanan data pengguna real-time menggunakan Firestore.
* **📱 Cross-Platform:** Berjalan mulus di Android dan iOS.

## 🛠️ Teknologi yang Digunakan

* **Frontend:** React Native, Expo, TypeScript
* **Backend / Auth:** Firebase (Authentication & Firestore)
* **AI Engine:** Google Gemini API
* **Navigation:** React Navigation
